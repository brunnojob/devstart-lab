Two Sum.
One useful pattern.

Practice arrays, dictionary lookups and time complexity with an original guide inspired by LeetCode 1: Two Sum.

The challenge

Return the zero-based indices of two distinct elements whose values add up to a target. Never reuse the same element. LeetCode guarantees one valid pair; either index order is accepted.

nums = [2, 7, 11, 15]
target = 9
result = [0, 1]

Try a nested-loop solution first. Then ask: can you find a previously visited complement without scanning the list again?

Hints, one step at a time

1. Find what is missing

For each number, compute complement = target − number.

2. Remember previous numbers

Use a dictionary that maps each visited number to its index.

3. Avoid matching an element with itself

Look up the complement before storing the current number. This also handles duplicate values at distinct indices.

Reveal the Python solution
class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        seen: dict[int, int] = {}
        for index, number in enumerate(nums):
            complement = target - number
            if complement in seen:
                return [seen[complement], index]
            seen[number] = index
        return []

This class matches LeetCode's Python 3 interface. As an extension, it returns [] if no pair exists. It does not modify the input.

Explain the trade-off

Nested loops: O(n²) time, O(1) auxiliary space. A dictionary: expected O(n) time and O(n) auxiliary space, assuming average O(1) hash lookup and insertion.

Check the edge cases

  • [3, 3], target 6 → [0, 1]
  • [0, 4, 3, 0], target 0 → [0, 3]
  • [-3, 4, 3, 90], target 0 → [0, 2]
  • [3], target 6 → [] in our extended contract
