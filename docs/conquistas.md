# Conquistas do GitHub com contribuições reais

GitHub Achievements são mostrados no perfil após certos eventos. Segundo a [referência oficial do perfil](https://docs.github.com/pt/account-and-profile/reference/profile-reference#earning-achievements), esta funcionalidade está em prévia pública e pode mudar. Clique ou passe o cursor sobre uma conquista no seu perfil para ver as dicas e, quando disponíveis, os eventos que contribuíram. O GitHub não garante um badge só porque você seguiu uma lista de passos.

| Conquista | Caminho útil | Leia mais |
| --- | --- | --- |
| Pull Shark | Abra PRs com mudanças reais, participe da revisão e acompanhe a integração. | [Criar PR](https://docs.github.com/pt/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request) |
| Pair Extraordinaire | Trabalhe em conjunto e registre a coautoria de commits apenas quando a outra pessoa efetivamente contribuiu e concordou. | [Múltiplos autores](https://docs.github.com/pt/pull-requests/committing-changes-to-your-project/creating-and-editing-commits/creating-a-commit-with-multiple-authors) |
| Galaxy Brain | Responda dúvidas de forma útil em Discussions; a pessoa autora ou a moderação pode escolher uma resposta como solução. | [Discussions](https://docs.github.com/pt/discussions/collaborating-with-your-community-using-discussions/participating-in-a-discussion) |
| Starstruck | Publique uma ferramenta ou material bem explicado, mantenha o projeto e permita que outras pessoas decidam estrelá-lo. | [Estrelas](https://docs.github.com/pt/get-started/exploring-projects-on-github/saving-repositories-with-stars) |

## Plano saudável de participação

1. Resolva um problema seu e documente como outra pessoa pode reproduzir a solução.
2. Divida o trabalho em issues específicas e deixe a entrada para iniciantes clara.
3. Revise contribuições com atenção e agradeça o trabalho recebido.
4. Compartilhe o resultado em comunidades onde ele é relevante, sem spam e sem trocas artificiais de estrelas.
5. Melhore o projeto conforme o feedback; badges e estrelas não são uma medida confiável de aprendizado.

A coautoria exige contribuição verdadeira. Respostas em discussões devem ajudar quem perguntou. PRs vazios ou repetitivos desperdiçam o tempo das pessoas mantenedoras. Consulte sempre o GitHub Docs e as dicas do seu perfil para confirmar regras atuais.
